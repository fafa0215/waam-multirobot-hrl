# 원본 HRL · HRL 적용본(버전 A) · CP-SAT C1 비교

생기원 단층 형상(280비드) 기준입니다. **형상**은 생기원 형상에 맞추려고 바꾼 부분이고, **방법**은 알고리즘 규칙을 바꾼 부분입니다.

- 원본 HRL은 안정민 석사학위논문(2026.02)의 계층적 강화학습입니다.
- 버전 A는 이 저장소에서 원본 HRL을 생기원 형상에 옮긴 적용본입니다.
- CP-SAT C1은 같은 과제의 CP-SAT 계열 방법이 낸 선택 해입니다. 이 저장소에서 같은 감사 조건으로 복원하고 다시 검사했습니다.

## 정리

- 버전 A는 형상 적응(1~3절)은 맞게 했지만, 4·5절에서 방법 자체를 바꿨습니다. 3D 위반의 직접 원인은 5절에서 충돌 검사를 적층 자세로만 좁힌 결정입니다.
- 1,263초와 2,066초의 차이에는 방법 차이와 자유도 차이가 섞여 있습니다. C1은 비드 방향 반전과 연결 경로 분할을 쓸 수 있고, 버전 A는 쓰지 못합니다.
- 공정한 비교를 위해서는 형상 적응만 하고 4·5절을 원본으로 되돌린 HRL(버전 B)과, 방향 고정·연결 경로 유지 조건의 C1을 비교해야 합니다. 이것이 다음 단계입니다.
